# 用户角色

**Why:** 了解用户背景有助于提供针对性的帮助和沟通方式。

**How to apply:** 根据用户的技术背景调整解释深度和方式。

## 角色

- 项目负责人，负责CRM系统的整体架构和开发规划
- 具备后端Java/Spring Boot和前端Vue/TypeScript开发能力
- 熟悉多租户架构、数据权限设计

## 开发偏好

- 遵循CLAUDE.md中定义的代码规范
- 使用TDD工作流（先写测试再实现）
- 使用planner agent进行复杂功能规划
- 使用code-reviewer agent进行代码审查
- 喜欢简洁的回复，不需要长篇解释
